How updates work

All skills live in one company GitHub repository — the single source of truth. When a skill is improved there:

  1. Claude Code users with auto-update on get it automatically.
  2. Codex users run the installer command again (Option 1) — that’s the whole update.

If an update ever breaks a skill, the company can roll back to any earlier version — every change is kept in history.

Security & privacy

  • The skills repository is currently public — no GitHub account or login is needed to install.
  • The installer will never ask for a password. If anything asks for your GitHub password during setup, stop and contact support.
  • The installer only manages the Hat Fella skill links it created itself (it keeps a manifest). Your personal skills and files are never touched.
  • No sudo, no admin rights, nothing installed system-wide.
  • Anyone can inspect the installer on GitHub before running it.

Troubleshooting

“git is not installed” or a popup about developer tools appears

Your Mac needs Apple’s free command-line tools first. Click Install on the popup (or run xcode-select --install in Terminal), wait for it to finish, then run the install command again.

I pasted the command but got an error

Make sure you copied the whole command with the Copy button — it must start with curl and end with | bash. Copy it again and paste as one line.

Codex doesn’t show the new skills

Fully quit Codex and open it again — skills load at startup. If they still don’t appear, run the install command again and read its final message.

The installer says my copy has “local changes”

Someone edited skill files directly on your computer, so the installer stopped rather than overwrite them. Ask whoever manages the skills to look at the ~/HFPskills folder — nothing was deleted.

The installer says a skill was “skipped”

You already have a personal skill with the same name. The installer never overwrites your own skills — rename your personal one if you want the Hat Fella version.

How do I update?

Run the same install command again (Option 1). It pulls the latest skills and refreshes everything. Claude Code users with auto-update on don’t need to do anything.

FAQ

What is a “skill”?

A written standard-operating-procedure the AI reads before doing a task — how we book a shoot, deliver a listing, run payroll. It makes the AI do the task the Hat Fella way, every time.

Do I need a GitHub account?

No. The repository is public, so installing and updating needs no login at all.

Does this cost anything or send my data anywhere?

No. It downloads text files to your computer and links them where Codex or Claude can read them. Nothing is uploaded.

Can I uninstall?

Yes — delete the ~/HFPskills folder and the Hat Fella links in your skills folder (they’re listed in the installer’s manifest file). Your own skills stay.

Who do I ask for help?

Email and describe what you saw — a screenshot of the Terminal helps.
