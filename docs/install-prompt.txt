   curl -fsSL https://raw.githubusercontent.com/frankhatfellaaiagent-del/HFPskills/main/install.sh | bash

4. Verify: list the contents of the skills folder the installer reported and confirm each Hat Fella skill is a symlink that resolves to a SKILL.md inside ~/HFPskills.
